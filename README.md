# HaptiRide | Sitio HTML5

## Abrir en Visual Studio Code
1. Descomprime el ZIP.
2. Abre la carpeta `HaptiRide_VSCode` desde Visual Studio Code (Archivo > Abrir carpeta).
3. Abre `index.html` en el navegador. También puedes usar la extensión Live Server.

## Estructura
- `index.html`: HTML5 semántico, menú horizontal y siete secciones según la guía.
- `styles.css`: estilos responsive, basados en los colores del código Figma proporcionado.
- `script.js`: demostración visual de señales y validación local del formulario.
- `imagenes/`: logotipo e ilustraciones SVG de ejemplo.
- `videos/`: coloca `haptiride.mp4` aquí si cuentas con un video.

**Nota:** Las citas de testimonios son ejemplos hipotéticos, las imágenes son ilustraciones propias de reemplazo y el formulario no envía correos. Reemplaza por contenido real del equipo antes de la entrega final. No requiere instalar Node, React ni dependencias.


## Integración Semana 10 + Semana 11
Esta versión conserva las interacciones y estructura modular de Semana 10 e incorpora el selector de modos de ruta (Segura, Rápida y Confort) de Semana 11. El selector actualiza el estado y la descripción de forma dinámica.

**Importante:** los tiempos, niveles de tráfico y descripciones son datos demostrativos; no representan rutas GPS ni tráfico en tiempo real. El formulario mantiene validación local y no envía mensajes a un servidor.
